# GESCO Android

Application Flutter de gestion scolaire, hors connexion, avec base SQLite locale.

Le projet Android reprend le socle Flutter de GESCO et sera enrichi progressivement avec les fonctions de gestion, notes, classements, bulletins PDF, fiches professeurs, import/export et sauvegardes.

## Build Android

Le workflow GitHub Actions construit et publie l'APK comme artefact après validation du code.
